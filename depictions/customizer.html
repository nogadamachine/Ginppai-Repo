Ginppai-Kakao-Customizer

광고 자리는 긴빠이치고, 필요한 화면만 남깁니다.

3.0.0 / 만든이 @nogadamachine / GPL-3.0 License

카카오톡 26.7.3 전용 / iOS 17 이상

탈옥 환경은 DEB, 비탈옥 환경은 DYLIB와 LiveContainer 또는 SideStore용으로 준비한 IPA를 사용합니다.

3.0.0 정식판

삭제 전에 보관한 텍스트를 원래 말풍선과 빨간 삭제됨 표시로 확인합니다. 메시지 도구는 기본 메뉴 안에서 열고, 보관함은 수정 전 원문과 모든 변경 기록을 검색합니다. 삭제된 말풍선의 반응과 답장을 제한하고 기존 설정은 유지합니다.

친구 목록의 특별한 친구 프로모션 숨김, 더보기 영역별 표시, 촬영 정보 정리와 대화 편의 설정도 포함합니다. 기기에 보관되지 않은 삭제 원문과 사진, 영상은 복원하지 않습니다. 텍스트 서식은 새 전송을 지원하며 메시지를 수정하면 서식이 풀립니다.

정식판 DEB 및 비탈옥 묶음 다운로드 / 기능별 확인 범위

3.0은 GPL-3.0이며 기존 2.3.2의 MIT 고지는 유지합니다.

기능

  • 확인된 광고 영역 숨김, 숏폼 / 쇼핑 탭 정리.
  • 오픈채팅 우선 열기 및 다시 눌렀을 때 숏폼 전환 방지.
  • 시작 탭 / 알림 배지 / 통화 탭 / 빠른 설정.
  • 현재 / 이전 프로필 사진, 배경사진, 영상의 서버 원본 파일 저장.
  • 추가 UI 패치가 있을 때 국가 / 지역 선택. 계정과 전화번호 국가는 바꾸지 않습니다.

2.3.2 변경 사항

프로필 사진 / 영상을 크게 연 화면에서 위아래로 스크롤해도 저장 버튼이 같은 위치에 남습니다. 버튼을 한 번 누르면 현재 보이는 원본을 사진 앱에 바로 저장합니다. 파일 앱 내보내기 메뉴는 제거했습니다.

탈옥용 다운로드

  • 루트리스 DEB / iphoneos-arm64
  • 루트풀 DEB / iphoneos-arm

패키지 관리자로 설치 후 카카오톡을 다시 실행하세요. 카카오톡 설정 맨 아래에 트윅 메뉴가 생깁니다. DEB만 설치하면 국가 선택은 비활성화될 수 있습니다.

비탈옥용 다운로드

DYLIB + 설치 안내 + IPA 준비 도구 ZIP

SideStore로 설치한 LiveContainer의 카카오톡 전용 트윅 폴더에 DYLIB를 추가하거나, 본인의 IPA에 넣고 SideStore로 서명 / 설치합니다. 구버전 KakaoAdBlock.dylib와 동시에 넣지 마세요.

검증 범위

KakaoTalk 26.7.3 / iOS 26.1 / SideStore + LiveContainer에서 사진과 영상 저장, 화면 정리, 삭제된 텍스트, 메시지 도구와 보관함 검색을 확인했습니다. 로컬 검사 188건과 DEB / DYLIB / ZIP 서명 및 해시 검사를 통과했습니다. 영상은 1080×2356, 약 13.9초의 MP4 원본을 저장 / 재생했습니다. 탈옥 실기와 SideStore 직접 설치는 미검증입니다. 서버가 제공하지 않는 업로드 전 고해상도 원본을 복구하지는 못합니다.
