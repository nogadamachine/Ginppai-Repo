광고와 화면은 정리하고, 필요한 메시지와 원본 미디어를 보관합니다.

다운로드 및 설치

탈옥 기기

Ginppai Repo를 패키지 관리자에 추가하거나, 탈옥 환경에 맞는 DEB를 설치하세요.

루트리스 DEB

iphoneos-arm64 / 설치 경로: /var/jb

루트풀 DEB

iphoneos-arm / 기존 루트풀 환경

설치 후 카카오톡을 다시 실행하세요. 트윅 메뉴는 카카오톡 설정 맨 아래에 있습니다.

비탈옥 기기

DYLIB, 설치 안내와 IPA 준비 도구를 함께 받습니다.

비탈옥용 ZIP

LiveContainer의 카카오톡 전용 트윅 폴더에서 불러오거나, 본인의 IPA에 넣어 SideStore로 서명합니다. SideStore는 DYLIB 자체를 설치하지 않습니다.

일부 메시지 옵션과 기록 수신 경로는 추가 연결이 필요합니다. 구버전 KakaoAdBlock.dylib와 중복 설치하지 마세요.

주요 기능

광고와 화면 정리
지원되는 광고와 특별한 친구 프로모션, 숏폼과 쇼핑 탭을 숨깁니다. 친구 목록과 더보기 영역도 선택할 수 있습니다.
삭제 원문과 메시지 도구
삭제 전에 기기에 보관한 텍스트와 빨간 삭제 표시를 보여 줍니다. 기본 메시지 메뉴에서 정보, 읽음 목록과 변경 기록을 확인합니다.
변경 기록 검색
수정 전 원문을 포함한 기록을 검색하고 날짜, 기록 수와 삭제 상태를 확인합니다.
원본 사진과 영상
현재와 이전 프로필, 배경의 원본을 사진 앱에 저장합니다. 확대 화면의 저장 버튼은 스크롤해도 같은 위치에 남습니다.
대화와 개인정보 설정
새 메시지 서식, 안 읽은 수 확장, 입력 중 표시와 분석 요청 제한, 전송 사진의 촬영 정보 정리를 선택합니다.
시작 화면과 국가 선택
처음 열 탭과 빠른 설정을 고릅니다. 국가 화면 선택은 별도 UI 패치가 필요하며 계정과 전화번호 국가는 바뀌지 않습니다.

확인 범위와 제한

iOS 26.1 / KakaoTalk 26.7.3 / SideStore + LiveContainer에서 확인했습니다. 탈옥 실기와 SideStore 직접 설치는 미검증입니다.

기기에 보관되지 않은 삭제 원문과 삭제된 사진, 영상은 복원하지 않습니다. 새 메시지의 서식은 지원하지만 카카오톡 26.7.3에서 메시지를 수정하면 서식이 풀립니다.

프로필 사진과 MP4 원본 저장은 확인했으며 실제 HLS 프로필 영상은 미검증입니다. 모든 국가, 광고 위치와 고급 기능의 모든 경로를 보장하지 않습니다. JIT은 트윅 자체의 필수 조건이 아닙니다.
