Ginppai-Kakao-Customizer

광고와 탭을 정리하고, 메시지와 프로필 원본을 보관합니다.

3.1.0KakaoTalk 26.7.3 / 26.8.0

기능

화면 정리
광고, 특별한 친구, 숏폼과 쇼핑 탭 숨김.
메시지 도구
보관한 삭제 원문, 읽음 목록과 변경 기록 확인.
원본 저장
프로필 사진과 영상을 사진 앱에 저장.
맞춤 설정
더보기 메뉴, 시작 화면과 국가 화면 선택.

설치

탈옥

Repo에 소스를 추가하거나 DEB로 설치합니다.

루트리스 DEB루트풀 DEB

비탈옥

LiveContainer의 카카오톡 전용 트윅 폴더에 DYLIB를 넣습니다.

DYLIB 다운로드도구 포함 ZIPSideStore 및 추가 설치 안내

기존 KakaoAdBlock.dylib와 중복 설치하지 말고 교체한 뒤 다시 실행하세요. 카카오톡 설정 맨 아래의 Ginppai에서 조절합니다.

확인 범위

iOS 26.1 / LiveContainer에서 확인했습니다. 탈옥 실기와 SideStore 직접 설치는 미검증입니다.

기기에 보관되지 않은 삭제 원문은 복원하지 않습니다. 국가 화면 선택은 추가 패치가 필요합니다. 기본 키보드 수정은 iPad 트윅의 기능입니다.
