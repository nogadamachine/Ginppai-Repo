# Ginppai Repo

nogadamachine의 카카오톡 트윅 저장소.

```text
https://nogadamachine.github.io/Ginppai-Repo/
```

탈옥 기기는 Sileo / Zebra / Cydia에 위 주소를 추가하세요. 추가 오류나 중복 표시가 있으면 전용 주소 하나로 교체하세요.

- 루트리스: https://nogadamachine.github.io/Ginppai-Repo/rootless/
- 루트풀: https://nogadamachine.github.io/Ginppai-Repo/rootful/

Customizer는 iOS 17 이상이 필요하며 탈옥용 최신 패키지는 **3.1.0-1**입니다. RootHide는 지원하지 않습니다.

비탈옥은 각 트윅의 DYLIB와 설치 안내를 사용합니다.

| 트윅 | 버전 | 기능 |
|---|---|---|
| [Ginppai-Kakao-Customizer](https://github.com/nogadamachine/Ginppai-Kakao-Customizer) | 3.1.0 | 광고와 탭 정리, 메시지 도구, 프로필 원본 저장 |
| [Ginppai-Kakao-iPad](https://github.com/nogadamachine/Ginppai-Kakao-iPad) | 1.1.0 | iPad 기기 판정, 기본 키보드 배열 수정 |

KakaoTalk 26.7.3 / 26.8.0, iOS 26.1, LiveContainer에서 확인했습니다. 탈옥 실기와 SideStore 직접 설치는 미검증입니다.

[다운로드와 설치](https://nogadamachine.github.io/Ginppai-Repo/) / [개발자 @nogadamachine](https://www.instagram.com/nogadamachine/)

Kakao와 관계없는 비공식 프로젝트입니다. 저장소 갱신은 DEB 추가 후 `python3 generate.py` 후 `python3 verify.py`로 확인합니다. 이전 DEB는 보관하고 목록에는 환경별 최신 버전만 표시합니다.
