기능 / 설치법 / 검증 범위 ↗

탈옥폰은 DEB, 비탈옥폰은 DYLIB

루트풀은 iphoneos-arm, 루트리스는 iphoneos-arm64 DEB를 사용합니다. 비탈옥은 SideStore + LiveContainer에서 DYLIB를 불러오거나 본인의 IPA에 넣어 SideStore로 서명합니다. SideStore는 DYLIB 자체를 설치하지 않습니다.

확인한 범위를 적습니다

iOS 26.1의 LiveContainer 환경에서 개발 / 시험했습니다. 탈옥 기기 실사용과 SideStore 직접 설치는 미검증입니다. 커스터마이저의 국가 선택은 별도 UI 패치가 필요합니다. 자세한 범위는 각 프로젝트를 확인하세요.
